# AdaptiveLearn

Тренажёр Python с адаптивной сложностью. Проект для студенческой научной конференции.

Ученик выбирает тему и проходит сессию из 10 вопросов с выбором ответа. После
каждого ответа программа показывает объяснение и по простым правилам подбирает
сложность следующего вопроса. Сессии и ответы сохраняются в SQLite, на вкладке
«Прогресс» показываются статистика, график и выгрузка в CSV.

Система работает **по явным правилам**, а не на обученной модели искусственного
интеллекта. Платные API, интернет и учётные записи не нужны.

## Установка и запуск

Нужен Python 3.11 или новее.

### Windows (PowerShell)

```powershell
cd AdaptiveLearn
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Если PowerShell запрещает запуск скрипта активации, выполните один раз
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или используйте
командную строку (cmd): `.venv\Scripts\activate.bat`.

### macOS / Linux

```bash
cd AdaptiveLearn
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется по адресу http://localhost:8501.

### Тесты

```bash
python -m pytest
```

## Возможности

- Три темы: «Переменные и типы данных», «Условия», «Циклы».
- 45 вопросов (по 15 на тему, по 5 на каждый уровень сложности) в `content/questions.json`.
- Сессия из 10 вопросов, первый — средней сложности.
- Ответ фиксируется после проверки; показываются правильный ответ, объяснение и рекомендация.
- Защита от повторной отправки ответа и от повторения вопросов в сессии.
- Досрочное завершение: результат помечается как незавершённая сессия.
- Итоги: число верных ответов, точность, распределение вопросов по сложности,
  разбор ошибок, итоговый целевой уровень, график сложности.
- Вкладка «Прогресс»: завершённые сессии, число ответов, общая точность, точность по темам,
  график «Изменение сложности заданий» для выбранной сессии, выгрузка в CSV
  (UTF-8 с BOM, разделитель «;» — открывается в русском Excel).
- Демонстрационные сессии хранятся с отдельной пометкой и не попадают в статистику ученика.

## Правила адаптации

1. Сессия начинается с целевого уровня 2.
2. Два верных ответа подряд повышают целевой уровень на 1.
3. Один неверный ответ понижает целевой уровень на 1.
4. Уровень ограничен диапазоном 1–3.
5. Серия верных ответов обнуляется после ошибки или смены уровня.
6. Следующий вопрос выбирается среди незаданных вопросов целевого уровня; если их нет —
   ближайшего доступного уровня, при равном расстоянии — более лёгкого.
7. Фактическая сложность вопроса хранится отдельно от целевого уровня.
8. Seed генератора случайных чисел сохраняется в базе: при тех же ответах тот же seed
   даёт ту же последовательность вопросов.
9. Если вопросы закончились, сессия завершается корректно.

Алгоритм не измеряет уровень знаний и не гарантирует улучшения результатов обучения.

## Структура

```
AdaptiveLearn/
├── app.py               интерфейс Streamlit
├── adaptive.py          правила адаптации и логика сессии (без UI)
├── database.py          SQLite: сессии, ответы, статистика, CSV
├── content/questions.json
├── .streamlit/config.toml   тема оформления
└── tests/               pytest
```

База данных создаётся автоматически в `data/adaptivelearn.db`. Путь можно изменить
переменной окружения `ADAPTIVELEARN_DB`. Все запросы параметризованы.

## Проверка алгоритма и исследование эффективности

Это две разные задачи.

**Проверка алгоритма (выполнена).** Автоматические тесты в `tests/` проверяют, что
программа делает ровно то, что описано в правилах: начальный уровень, повышение и
понижение, границы, сброс серии, выбор ближайшего уровня, отсутствие повторов,
воспроизводимость по seed, защиту от повторной отправки, сохранение в базу.
Тесты банка вопросов проверяют структуру, количество и уникальность, а для вопросов
вида «Что выведет код?» — запускают фрагмент кода и сверяют реальный вывод Python
с отмеченным правильным ответом.

**Исследование учебной эффективности (не проводилось).** Гипотеза проекта:
«Подбор сложности по ответам ученика может помочь сделать учебную тренировку более
подходящей к его текущим результатам». Чтобы её проверить, нужно отдельное
исследование с участниками: например, сравнение с контрольной группой, которая
получает вопросы фиксированной сложности, с предварительным и итоговым тестом и
опросом. Таких данных у проекта пока нет, и никакие результаты исследования
здесь не заявляются.

## Сценарий демонстрации (около 3 минут)

1. Вкладка «О проекте»: кратко назначение и правила адаптации (30 с).
2. Вкладка «Тренировка»: выбрать тему, отметить «Демонстрационная сессия»,
   нажать «Начать тренировку». Показать: вопрос средней сложности, целевой уровень 2.
3. Ответить верно на два вопроса. После второго — сообщение «целевой уровень повышен 2 → 3»,
   следующий вопрос сложный.
4. Ответить неверно — «целевой уровень понижен 3 → 2», показать объяснение и рекомендацию.
5. Нажать «Завершить досрочно»: результат помечен как незавершённая сессия; показать
   разбор ошибок и график «Изменение сложности заданий».
6. Вкладка «Прогресс» → «Демонстрационные сессии»: та же сессия на графике, выгрузка CSV.
   Обратить внимание, что учебная статистика демонстрацией не изменилась.

## Ограничения

- Небольшой банк вопросов, только выбор ответа; написание кода не проверяется.
- Уровни сложности назначены экспертно, без статистической калибровки.
- Простые правила: не учитываются время ответа, повторение материала, типичные ошибки.
- Нет учётных записей — статистика относится к одному локальному пользователю.
- Сессия, прерванная закрытием вкладки браузера, остаётся в базе со статусом «Не завершена»;
  её ответы учитываются в статистике ответов, но не в числе завершённых сессий.
- Учебная эффективность не исследовалась.
